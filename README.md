
# Mini Mercado

Sistema de terminal desenvolvido em Java para gerenciamento de um mini mercado.

## Funcionalidades

- Cadastro, consulta, alteração e remoção de produtos
- Cadastro, consulta, alteração e remoção de clientes
- Realização de compras
- Controle de estoque
- Persistência de dados em arquivos CSV

## Tecnologias utilizadas

- Java
- Arquivos CSV
- GitHub

## Como executar o projeto

1. Clone este repositório.
2. Abra o projeto em uma IDE Java, como NetBeans.
3. Execute o arquivo Main.java.
4. Utilize o menu apresentado no terminal para navegar pelo sistema.

## Objetivo

Aplicar os conceitos de programação estudados na disciplina, como classes, objetos, estruturas condicionais, estruturas de repetição, vetores, modularização e persistência de dados.
